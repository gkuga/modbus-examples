# 電力計 Modbus 通信仕様書

| 項目 | 内容 |
| --- | --- |
| 対象機器 | 単相電力計 (太陽光発電付き住宅の分電盤用) |
| 文書版数 | 1.0 |
| レジスタマップ版数 | 1 |

この文書は、電力計に Modbus TCP で接続するクライアント (マスタ) を実装する人向けの仕様である。
本リポジトリの `server.py` はこの仕様のシミュレータで、異なる点は [9. シミュレータとの差異](#9-シミュレータとの差異) にまとめる。

## 1. 概要

電力計は系統との接続点で電圧・電流・有効電力などを計測し、Modbus TCP のサーバ (スレーブ) として値を提供する。
あわせて、負荷リレーの ON/OFF と、電力超過アラームのしきい値の設定ができる。

### 1.1 符号の定義

| 量 | 正 | 負 |
| --- | --- | --- |
| 有効電力 | 買電 (系統から受電) | 売電 (系統へ逆潮流) |
| 電流 | 向きを持たない (常に 0 以上) | — |

### 1.2 準拠規格

- Modbus Application Protocol Specification V1.1b3
- Modbus Messaging on TCP/IP Implementation Guide V1.0b

## 2. 通信仕様

| 項目 | 値 |
| --- | --- |
| 物理層 | Ethernet 10BASE-T / 100BASE-TX |
| プロトコル | Modbus TCP |
| TCP ポート | 502 |
| Unit ID | 1 |
| 同時接続数 | 最大 4。5 本目の接続は受け付けない |
| 応答時間 | リクエストの受信から 100 ms 以内 |
| 無通信タイムアウト | 60 秒間リクエストがない接続はサーバ側から切断する |
| 推奨ポーリング周期 | 1 秒以上 (計測値は 1 秒ごとに更新するので、これより速く読んでも同じ値になる) |

Unit ID 1 以外を指定したリクエストには、例外コード 0x0B (Gateway Target Device Failed to Respond) を返す。

## 3. 対応ファンクションコード

| FC | 名称 | 対象 | 1 回の最大数 |
| --- | --- | --- | --- |
| 0x01 | Read Coils | コイル | 1 |
| 0x02 | Read Discrete Inputs | ディスクリート入力 | 1 |
| 0x03 | Read Holding Registers | 保持レジスタ | 2 |
| 0x04 | Read Input Registers | 入力レジスタ | 8 |
| 0x05 | Write Single Coil | コイル | 1 |
| 0x06 | Write Single Register | 保持レジスタ | 1 |
| 0x0F | Write Multiple Coils | コイル | 1 |
| 0x10 | Write Multiple Registers | 保持レジスタ | 2 |

上記以外のファンクションコードには例外コード 0x01 (Illegal Function) を返す。

## 4. データ型

1 レジスタは 16 bit で、レジスタ内のバイト順は Modbus の規定どおりビッグエンディアン (上位バイトが先) とする。

| 型 | レジスタ数 | 内容 |
| --- | --- | --- |
| UINT16 | 1 | 符号なし整数 0〜65535 |
| INT16 | 1 | 符号付き整数 -32768〜32767 (2 の補数) |
| UINT32 | 2 | 符号なし整数 0〜4294967295 |
| FLOAT32 | 2 | IEEE 754 単精度浮動小数点数 |

**32 bit 型のワードオーダー (2 つのレジスタのどちらを上位とするか) はレジスタごとに異なる。**
必ず 5 章の表の「ワードオーダー」列に従うこと。

- 上位先: 小さいアドレスに上位 16 bit を置く
- 下位先: 小さいアドレスに下位 16 bit を置く

例: UINT32 の値 123456 (0x0001E240) を下位先で置くと、`[n] = 0xE240, [n+1] = 0x0001` になる。

## 5. レジスタマップ

アドレスは PDU 上のアドレス (0 始まり) で示す。「番号」は慣習的な 1 始まりの表記で、先頭の桁がテーブルを表す。
マップにないアドレスを含むリクエストには、例外コード 0x02 (Illegal Data Address) を返す。

### 5.1 コイル (読み書き)

| アドレス | 番号 | 名称 | 値 | 電源投入時 |
| --- | --- | --- | --- | --- |
| 0 | 00001 | 負荷リレー | 1 = ON (負荷へ給電する), 0 = OFF | 電源を切る直前の状態に戻る |

### 5.2 ディスクリート入力 (読み取り専用)

| アドレス | 番号 | 名称 | 値 |
| --- | --- | --- | --- |
| 0 | 10001 | 電力超過アラーム | 1 = 発報中, 0 = 発報していない (判定は 6.2 節) |

### 5.3 入力レジスタ (読み取り専用) — 計測値

| アドレス | 番号 | 名称 | 型 | ワードオーダー | 倍率・単位 | 範囲 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 30001 | 電圧 | UINT16 | — | 0.1 V | 0.0〜300.0 V |
| 1 | 30002 | 電流 | UINT16 | — | 0.01 A | 0.00〜120.00 A |
| 2 | 30003 | 有効電力 | INT16 | — | 1 W | -32767〜32767 W (1.1 節の符号) |
| 3 | 30004 | 力率 | UINT16 | — | 0.001 | 0.000〜1.000 |
| 4-5 | 30005-30006 | 周波数 | FLOAT32 | 上位先 | Hz | 45.0〜65.0 Hz |
| 6-7 | 30007-30008 | 積算電力量 (買電) | UINT32 | **下位先** | 1 Wh | 0〜4294967295 Wh |

値は「生の値 × 倍率」で物理量に戻す。例: 電圧の生の値が 1015 なら 101.5 V。

範囲外・計測不能のときの値:

| 名称 | 値 |
| --- | --- |
| 有効電力 | ±32767 W を超えたら ±32767 で頭打ちにする (2 の補数で折り返さない) |
| 周波数 | 電圧がないなどで計測できないときは NaN (0x7FC0, 0x0000) |
| 積算電力量 | 4294967295 Wh の次は 0 に戻る |

### 5.4 保持レジスタ (読み書き) — 設定

| アドレス | 番号 | 名称 | 型 | 内容 | 書き込める値 | 初期値 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 | 40001 | アラームしきい値 | UINT16 | 1 W | 0〜32767 | 1000 |
| 1 | 40002 | 積算電力量リセット | UINT16 | 1 を書くと積算電力量 (30007-30008) を 0 にする。読むと常に 0 | 1 | 0 |

- 書き込める値の範囲外を書いたときは例外コード 0x03 (Illegal Data Value) を返し、値は変えない
- 0x10 で複数のレジスタに書くとき、1 つでも範囲外の値があれば全体を書き込まない
- アラームしきい値は不揮発メモリに保存し、電源を切っても保持する

## 6. 機器の動作

### 6.1 計測値の更新

- 計測値 (30001〜30008) は 1 秒ごとにまとめて更新する。各値はその 1 秒間の平均値
- 1 回のリクエストで返す値は、すべて同じ更新時刻のもの
- 積算電力量は有効電力が正 (買電) の間だけ増える。売電量は積算しない

### 6.2 電力超過アラーム (10001)

- 有効電力がしきい値 (40001) を超えると 1 になる
- 有効電力が「しきい値 − 50 W」以下になると 0 に戻る (しきい値付近で値がばたつかないようにするためのヒステリシス)
- 判定は計測値の更新ごと (1 秒ごと) に行う

### 6.3 負荷リレー (00001)

- OFF にすると負荷へ給電しなくなる。太陽光発電の分だけ有効電力が負 (売電) になる
- リレーの切り替えは、次の計測値の更新から反映される

## 7. 例外応答

| 例外コード | 名称 | 返す条件 |
| --- | --- | --- |
| 0x01 | Illegal Function | 3 章にないファンクションコード |
| 0x02 | Illegal Data Address | マップにないアドレスを含む、または 1 回の最大数を超える |
| 0x03 | Illegal Data Value | 保持レジスタに書き込める値の範囲外を書いた |
| 0x04 | Server Device Failure | 計測回路の故障など、機器の内部異常 |
| 0x0B | Gateway Target Device Failed to Respond | Unit ID が 1 以外 |

## 8. クライアント実装上の注意

1. **32 bit の値は、2 つのレジスタを 1 回のリクエストで読むこと。**
   30007 と 30008 を別々に読むと、間に計測値が更新された場合、下位ワードが繰り上がる前と後の値を組み合わせてしまい、値が壊れる。
2. **同じ時刻の計測値が必要なら、30001〜30008 を 1 回で読むこと。** 分けて読むと、電圧と電流が別の時刻の値になることがある。
3. **ワードオーダーを決め打ちしないこと。** 周波数 (上位先) と積算電力量 (下位先) で違う。
4. **有効電力は INT16 として読むこと。** UINT16 として読むと、売電中の値が 65000 前後の大きな値になる。
5. 積算電力量の差分 (一定期間の使用量) を計算するときは、0 に戻ること (5.3 節) と、リセット (40002) によって値が減ることを考慮すること。
6. 設定 (40001, 40002, 00001) を複数のクライアントから書き込まないこと。機器には排他制御の仕組みがない。
7. Modbus TCP には認証も暗号化もない。電力計は外部から接続できないネットワークに置くこと。

## 9. シミュレータとの差異

`server.py` は学習用のシミュレータで、次の点がこの仕様と異なる。

| 項目 | 仕様 | `server.py` |
| --- | --- | --- |
| 待ち受けアドレス | 0.0.0.0:502 | 127.0.0.1:5020 |
| 同時接続数・無通信タイムアウト | 4 本, 60 秒 | 制限なし |
| 計測値の更新 | 1 秒ごと | 入力レジスタを読むたびに新しい値を作る (1 回のリクエスト内の値は同じ時刻のもの) |
| 時間の進み方 | 実時間 | 60 倍速 (積算電力量が目に見えて増えるように) |
| 有効電力の範囲外 | ±32767 で頭打ち | 折り返す (`& 0xFFFF`)。ただしシミュレートする範囲 (約 -650〜750 W) では起きない |
| 周波数の NaN | 計測不能時 | 起きない |
| アラームのヒステリシス | 50 W | なし (読むたびにしきい値と比較する) |
| 保持レジスタの値の検査 | 範囲外は例外 0x03 | 何でも受け付ける。40002 に 1 以外を書くと無視する |
| 設定・リレー状態の保存 | 不揮発 | メモリ上のみ (再起動で初期値に戻る) |
| Unit ID 1 以外 | 例外 0x0B | 例外 0x04 |
| コイル アドレス 1 以降 | 例外 0x02 | 読み書きできてしまう (内部で 16 bit 単位に詰めているため) |
| 3 章にない FC | 例外 0x01 | pymodbus が対応しているもの (0x08, 0x2B など) には応答する |

## 付録 A. フレーム例

MBAP ヘッダ (トランザクション ID 2 バイト, プロトコル ID 2 バイト, 長さ 2 バイト, Unit ID 1 バイト) の後に PDU が続く。

### 計測値の一括読み出し (FC 0x04, アドレス 0 から 8 個)

```
要求: 00 01 00 00 00 06 01 04 00 00 00 08
応答: 00 01 00 00 00 13 01 04 10 03 f7 01 11 fe ef 03 da 42 48 11 ee e2 40 00 01
```

応答の解釈:

| レジスタ | 生の値 | 型 | 値 |
| --- | --- | --- | --- |
| 30001 | 0x03F7 | UINT16 × 0.1 | 101.5 V |
| 30002 | 0x0111 | UINT16 × 0.01 | 2.73 A |
| 30003 | 0xFEEF | INT16 | -273 W (売電) |
| 30004 | 0x03DA | UINT16 × 0.001 | 0.986 |
| 30005-30006 | 0x4248, 0x11EE | FLOAT32 上位先 | 50.02 Hz |
| 30007-30008 | 0xE240, 0x0001 | UINT32 下位先 | 123456 Wh |

### 範囲外の読み出し (FC 0x04, アドレス 0 から 9 個)

```
要求: 00 02 00 00 00 06 01 04 00 00 00 09
応答: 00 02 00 00 00 03 01 84 02          (FC | 0x80 = 0x84, 例外コード 0x02)
```

### 負荷リレーを OFF にする (FC 0x05)

```
要求: 00 03 00 00 00 06 01 05 00 00 00 00   (ON は 00 00 ff 00)
応答: 00 03 00 00 00 06 01 05 00 00 00 00   (要求と同じ内容が返る)
```
